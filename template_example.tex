\section{Introduction}
This document serves as a professional template demonstrating the usage of the `altair\_professional` LaTeX class. It includes various custom environments and styling elements designed for consistency across different document types like manuals, letters, or scope of work documents.

\subsection{Purpose of this Template}
This template aims to provide a standardized structure and aesthetic for documents produced by \companyName. By using this class, users can focus on content while maintaining a professional and consistent appearance.

\section{Key Features}
This template includes:
\begin{itemize}
  \item Standardized title page with configurable project details.
  \item Custom header and footer for branding and navigation.
  \item Professional color palette.
  \item Specialized boxes for code listings, information notes, and warnings.
\end{itemize}

\subsection{Code Examples}
Here are examples of how to use the custom code listing environments:

\begin{terminal}{Linux Command Example}
  $ ls -la /path/to/your/project
  $ git status
  # This is a comment
\end{terminal}

\begin{powershell}{Windows PowerShell Example}
  PS C:\> Get-Service -Name "w3svc"
  PS C:\> ipconfig /all
  # PowerShell comments start with a hash
\end{powershell}

\begin{sqlbox}{SQL Query Example}
  SELECT * FROM users WHERE status = 'active';
  INSERT INTO products (name, price) VALUES ('New Item', 99.99);
\end{sqlbox}

\begin{pythonbox}{Python Example}
  def greet(name):
      # Strings and comments are highlighted independently.
      print(f"Hello, {name}!")

  greet("Altair")
\end{pythonbox}

\begin{cbox}{C Example}
  #include <stdio.h>

  int main(void) {
      printf("Hello, Altair!\n");
      return 0;
  }
\end{cbox}

The generic \texttt{codebox} environment supports other languages known to the
\texttt{listings} package by accepting the language name before the title.

\begin{codebox}{Java}{Generic Java Example}
  public class Example {
      public static void main(String[] args) {
          System.out.println("Hello, Altair!");
      }
  }
\end{codebox}
